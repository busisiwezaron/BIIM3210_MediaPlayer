BIIM3210 INTERACTIVE MULTIMEDIA
Assignment 2: Media Player in JavaFX

PROJECT
Zaron Media Player

REQUIREMENTS COVERED
1. JavaFX MediaPlayer and MediaView for audio/video playback.
2. Play, Pause and Stop controls.
3. Keyboard controls:
   Spacebar = Play/Pause
   S = Stop
   N = Next
   P = Previous
   Up Arrow = Increase volume
   Down Arrow = Decrease volume
   M = Mute/Unmute
4. Playlist using ListView.
5. Add media using FileChooser.
6. Remove selected media.
7. Clear playlist.
8. Selecting a playlist item automatically loads it.
9. Previous/Next navigation.
10. Volume slider and progress slider.

HOW TO RUN IN VS CODE
1. Open the folder in VS Code.
2. Open Terminal.
3. Make sure the terminal is at the project root.
4. Run:

   mvn clean javafx:run

The project uses JavaFX 25.0.2 and Maven.

IMPORTANT
The application does not include media files. Use ADD MEDIA to select supported audio/video files from your computer.

SUPPORTED EXAMPLES
.mp4, .m4v, .fxm, .flv, .mp3, .m4a, .wav, .aiff, .aif

KEYBOARD SHORTCUTS
Space = Play/Pause
S = Stop
N = Next
P = Previous
Up = Volume Up
Down = Volume Down
M = Mute/Unmute
